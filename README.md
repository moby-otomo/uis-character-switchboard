# UIS Character Switchboard

**A character-generation and classification workbench for Uncles in Space.**

The **UIS Character Switchboard** is an experimental system for generating, preparing, and classifying characters within the *Uncles in Space* universe.

It is part of **Moby Otomo**, a larger body of work exploring how AI can participate in creative thinking while the human remains responsible for direction, judgment, classification, and meaning.

Rather than treating AI simply as a generator of finished content, the Switchboard treats character creation as a **systematic, artifact-centered process**.

## What is a Character Switchboard?

A switchboard is a place where different inputs, rules, components, and possibilities can be routed into different configurations.

The UIS Character Switchboard applies this idea to character creation.

A character can be understood not merely as an image or a prompt, but as a collection of structured properties:

* visual characteristics
* behavioral traits
* occupations and roles
* quirks and habits
* cultural or linguistic details
* philosophical tendencies
* relationships to other characters
* taxonomic classifications
* generated artifacts

The purpose of the system is to make these elements **combinable, inspectable, and classifiable**.

## Why it exists

*Uncles in Space* began as a fictional universe populated by peculiar elderly gentlemen.

The deeper project became an investigation into something more interesting:

> **What happens when character creation becomes a process of classification, recombination, observation, and co-thinking with AI?**

The Switchboard is one experiment in answering that question.

It sits somewhere between:

**character generator → taxonomy engine → creative workbench → worldbuilding system**

The objective is not maximum randomness.

It is to create a system in which unexpected combinations can produce characters that are sufficiently strange to be interesting, yet sufficiently structured to belong to the same world.

## Relationship to Moby Otomo

The UIS Character Switchboard is a project within the broader **Moby Otomo** ecosystem.

Moby Otomo explores a recurring progression:

**messy accumulation → classification → taxonomy → systems → worldbuilding**

The Switchboard occupies the **systems / worldbuilding** portion of that progression.

It is also an example of a broader working principle:

> **AI as archival assistant, co-thinker, and system component — not autonomous author.**

The human supplies direction, taste, judgment, and the conceptual frame.
The system helps generate, organize, transform, and inspect the resulting material.

## Project status

This repository is currently a **public workbench and project record**.

The Character Switchboard is being developed incrementally as part of the ongoing *Uncles in Space* project.

The repository may therefore contain periods of sparse implementation while the underlying system, taxonomy, documentation, and supporting artifacts are being developed elsewhere in the project ecosystem.

That is intentional.

The repository records the evolution of the system rather than presenting a manufactured appearance of completeness.

## Part of Uncles in Space

*Uncles in Space* is a fictional and experimental worldbuilding project involving:

* character taxonomy
* absurdist observation
* AI co-thinking
* visual artifacts
* fictional institutions
* strange classification systems
* conversations between humans, uncles, and machines

The Character Switchboard provides infrastructure for this larger universe.

## Design principle

The central question is not:

> **"Can AI make a character?"**

It is:

> **"What kind of creative system emerges when a human and AI repeatedly generate, classify, inspect, and recombine characters?"**

The resulting characters are artifacts of that process.

And the process itself becomes part of the world.
